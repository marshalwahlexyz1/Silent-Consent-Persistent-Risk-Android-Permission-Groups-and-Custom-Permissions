# AutoGrant Monitor APK Artifact

This directory contains the current APK artifact of the AutoGrant Monitor
prototype used in the update-time transparency pilot.

Included:

- `base.apk`: the recovered APK artifact for the prototype

Not included in this public release:

- device-specific logs
- app databases
- internal test state
- unresolved app-level disclosure data

The current release therefore provides the runnable APK artifact only.
